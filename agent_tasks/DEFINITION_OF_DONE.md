# Definition of Done

## Code feature
Done only if:
- tests exist;
- contract is respected;
- failure modes explicit;
- scientific choices are config-controlled;
- raw outputs saved;
- resumable;
- smoke test passes.

## Exploratory experiment
Done only if:
- resolved config saved;
- raw per-example results saved;
- controls included;
- confidence intervals computed;
- failures/skips logged;
- confirmation split untouched.

## Candidate pathway
Escalate only if:
- effect exceeds matched controls;
- >=3 seeds agree qualitatively;
- one transformation test completed;
- held-out confirmation supports effect;
- >=2 plausible artifacts explicitly tested;
- next-step compute estimate documented.

## Not sufficient
These alone are not findings:
- high AUROC;
- one significant layer;
- steering changes output;
- separated PCA;
- one-model reproduction.
