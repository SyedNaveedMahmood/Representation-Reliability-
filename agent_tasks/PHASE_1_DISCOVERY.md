# Phase 1 Discovery Procedure

## E00
Freeze high/mid/low-D site selection using discovery data only.

## E01
Plot D vs C.

### If D and C align
Do not force a gap.
Proceed to E02 and E07.

### If D appears before C
Replicate with:
- 3 seeds;
- second token selector;
- paraphrase.

Test alternative explanations:
- wrong intervention site;
- distributed representation;
- source/base mismatch.

### If C exists where D is weak
Test whether:
- linear probe is geometrically inadequate;
- causal structure is subspace/component-based.

## E02/E03
For every candidate:
- full alpha curve;
- random controls;
- utility drift;
- delta/activation norm;
- off-manifold proxy.

Do not say "unsteerable" from additive failure alone.

## E04
Use exact corruption labels.
Compare corruption-state vs final-error monitoring on identical states.

## E05
Rank reasoning steps by geometry, then causally test top/bottom/random groups before expensive exhaustive scans.

## E07 before scaling
Any D/C/S phenomenon gets at least:
- paraphrase;
- question reframing;
- benign distractor.
